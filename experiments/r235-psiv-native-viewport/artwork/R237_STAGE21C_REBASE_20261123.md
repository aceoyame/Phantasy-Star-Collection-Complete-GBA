## Newly discovered real collision

A direct three-way rebase onto Stage21C found 2,068 nonidentical changed bytes, **all confined to ROM offsets \`0x0122B001..0x0122B953\`**. Stage14 used the \`0x0922B000\` expansion bank for Genesis artwork; R237 compiled palette, Fin, and title ARM routines into the same bank. Blindly applying the binary patch would corrupt the native art; blindly overlaying the art would destroy R237 code.

## Implemented source-only builder and private output

See [build_stage21c_r237_relocated.py](build_stage21c_r237_relocated.py). The builder:
- SHA-checks accepted R235, Stage14, Stage21C; proves Stage21C is a 22-byte delta from Stage14 in precisely the three documented ARM OAM regions.
- Rebuilds the exact original R237 via IPS32, preserving all its non-overlapping gameplay fixes.
- Restores the entire Stage21C native artwork content over the original R237 code allocation \`0x0922AF00..0x0922B9FF\`.
- Recompiles the **actual, user-supplied R237** \`palfix.c\`, \`finfix.c\`, and \`titlefix.c\` at a new, 64-byte aligned site starting at **\`0x0924CE40\`**. The next 8 KiB at that site were verified all-zero across accepted R235, Stage21C, and R237 before writing. This is an unused-byte proof, *not yet runtime proof that the bank is safe*.
- Retargets and verifies all five ARM BL call sites: \`0x0882F234\`, \`0x08822CBC\` (palette); \`0x08808CC8\`, \`0x08808CE4\` (Fin); \`0x08801214\` (title).
- Bit-checks the unchanged R237 SP literals, Saya event calls, and audio-mixer calls, plus Stage21C field-OAM stub, actor hook, GBA header, original art cave, and 32 MiB size. Refuses all unexplained collisions.

## Acceptance blockers

The code was built and byte-verified **without real emulator execution this run**: the remote Ryzen desktop was offline and the local scratch environment had no mGBA/VBA-M/Delta-style executables. The original Stage21C experimental audio PCM divergence and Academy first-room-reveal mismatch (frame 16571) are unresolved. Revisit the relocation bank's runtime safety, run clean boot + Saya + Zema + saves/erase + PD3→ending→Fin + field Academy in mGBA and VBA-M/Delta, compare graphics against Genesis, and record timing/stack/audio headroom before accepting anything.

Accepted R235, production R236/R237, and GitHub main were not modified. The work is restricted to the experimental branch; the build is not a public game release.
